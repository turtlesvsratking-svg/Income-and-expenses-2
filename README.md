# Income-and-expenses-2

# ブログ収支マネージャー | おしえてかめさん

ブログ運営における収入（カテゴリー別）と経費を管理・分析するためのPWA対応Webアプリケーションです。

## 主な機能
- **自動GAS連携**: Google Apps Scriptを通じてスプレッドシートへリアルタイム自動バックアップ。
- **PWA対応**: スマホのホーム画面に追加して専用アプリとして起動可能（アプリアイコン: `IMG_4711.png`）。
- **グラフ分析**: Chart.jsを用いた収入比率のドーナツグラフ表示。

## ファイル構成
- `index.html`: Webアプリ本体（タイトル横画像削除済み）
- `style.css`: レスポンシブデザイン
- `app.js`: 計算・グラフ・データ同期ロジック
- `manifest.json`: PWA設定ファイル
- `IMG_4711.png`: アプリアイコン画像
